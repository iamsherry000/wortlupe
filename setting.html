WORTLUPE · iPhone 設定教學

在 WhatsApp 看到德文，輕點手機背面兩下就能逐字查

Wortlupe 會把一整段德文變成「每個字都能點」的閱讀頁：點一下看原形、詞性、英文解釋，每一句還能展開文法講解。跟著下面三步設定一次，以後就不用再設定了。

  • 📱 iPhone
  • 🧭 Safari 瀏覽器
  • ⏱ 約 5 分鐘
1

把 Wortlupe 放到主畫面

這樣它就像一個 App，而且沒有網路也能用。

  1. 用 Safari 打開這個網址（一定要用 Safari，Chrome 做不到）：
    https://wortlupe.iamsherry000.workers.dev
  2. 點畫面下方的分享按鈕（方框加一個向上的箭頭）。
  3. 往下滑，點 Add to Home Screen （加入主畫面），再點右上角的 Add （新增）。
  4. 回到主畫面，點 Wortlupe 的圖示打開一次。它會趁這次把字典存進手機，之後就能離線用。
2

建一個「Wortlupe」捷徑

捷徑負責把你拷貝或分享的德文送進 Wortlupe。這一步最長，跟著做就好。

  1. 打開 iPhone 內建的 Shortcuts （捷徑） App。找不到的話，在主畫面往下滑搜尋「Shortcuts」或「捷徑」。
  2. 點右上角的 ＋ 新增一個捷徑，把名字改成 Wortlupe。
  3. 打開捷徑的詳細資訊：
    • 新版 iOS：點畫面最上方的捷徑名稱（旁邊有個小的 ⌄）→ Details （詳細資訊）。
    • 舊版 iOS：點畫面最下方的 ⓘ。
  4. 詳細資訊裡有一個開關 Show in Share Sheet （在分享表單中顯示），直接打開就好，Wortlupe 就會出現在分享選單裡。
  5. 接收的類型只留 Text （文字），其他全部取消。
  6. 回到編輯畫面，最上方會多出一行 Receive Text from Share Sheet。點裡面的 If there's no input （如果沒有輸入），改成 Get Clipboard （取得剪貼簿）。
    這一步最重要改了之後，同一個捷徑就能同時用在「分享選單」和「背面輕點」。
  7. 點下方的搜尋欄，找 Combine Text （合併文字），點它加進來。確認它寫的是 Shortcut Input （捷徑輸入），後面的分隔方式選 New Lines （換行）。
    一次轉傳好幾則訊息要靠這一步從 WhatsApp 一次選好幾則分享時，捷徑收到的是好幾段文字；沒有先合併，後面會變成好幾個網址，捷徑就會出錯。
  8. 再搜尋 URL Encode （URL 編碼），點它加進來。點它裡面的變數，改成 Combined Text （合併的文字）。
  9. 再搜尋 Text （文字） 加進來。在文字框裡貼上下面這串網址：
    https://wortlupe.iamsherry000.workers.dev/#t=
    貼好之後，游標停在最後面，點鍵盤上方出現的 URL Encoded Text （URL 編碼的文字），把它接在網址後面。
  10. 最後搜尋 Open URLs （打開 URL） 加進來，確認它寫的是 Text。
  11. 點右上角 Done （完成） 儲存。
3

設定「輕點手機背面兩下」

以後拷貝完德文，不用切換 App，敲兩下手機背面就好。

  1. 打開 Settings （設定）。
  2. 依序點 Accessibility （輔助使用） → Touch （觸控） → 拉到最下面的 Back Tap （背面輕點）。
  3. 點 Double Tap （點兩下），往下找到捷徑區，選 Wortlupe。
✓

開始使用

第一次使用時，iPhone 會問你能不能讀剪貼簿、能不能打開網址，兩個都選 Allow （允許）。

輕點背面最快

  1. 在 WhatsApp 長按一則德文訊息，點 Copy （拷貝）。
  2. 輕點手機背面兩下。Wortlupe 會自動打開，文字已經放好了。

分享選單

  1. WhatsApp：長按訊息 → Forward （轉寄） → 右下角的分享圖示 → Wortlupe。
  2. Safari、Mail、備忘錄：選取一段文字 → Share （分享） → Wortlupe。

不用捷徑的手動方式

  1. 拷貝德文 → 打開主畫面的 Wortlupe → 點 Paste。
?

常見問題

分享選單裡找不到 Wortlupe

先確認第 2 步的 Show in Share Sheet 有打開。它可能排在很後面：在分享選單最下面點 Edit Actions（編輯動作），把 Wortlupe 移到前面。

Wortlupe 打開了，但文字沒有進去

可能是舊版還留在手機裡。在 Wortlupe 頁面往下拉重新整理一次。也請檢查第 2 步的網址最後有沒有接上「URL Encoded Text」。

一次轉傳好幾則 WhatsApp 訊息就出錯

捷徑少了「Combine Text」那一步。打開捷徑，在 Receive 下面加上 Combine Text（分隔選 New Lines），再把 URL Encode 裡的變數改成 Combined Text。完成後應該是上面圖裡的五塊。

敲背面沒有反應

確認第 3 步選的是 Wortlupe。有手機殼的話要敲得用力一點，敲在手機背面中間偏上的位置。

為什麼打開的是 Safari，不是主畫面上的 Wortlupe？

這是 iPhone 的限制，捷徑只能用 Safari 打開網頁。兩邊都能離線使用，查字和文法講解都一樣。

我的訊息會被傳到網路上嗎？

不會。文字放在網址的 # 後面，瀏覽器不會把這一段送出去；查字和文法分析全部在手機裡完成。
